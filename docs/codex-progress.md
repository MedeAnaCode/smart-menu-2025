## 3. Авторизация и доступ

- Добавлен Keycloak 26.7.0 с импортом realm и публичным SPA-клиентом.
- Frontend использует `keycloak-js`, Authorization Code Flow с PKCE и `check-sso`; токены не сохраняются в `localStorage`.
- Backend проверяет JWT через JWKS, issuer, client id и обязательный `sub`.
- В realm добавлен mapper `sub` для lightweight access token.
- Все операции с личными рецептами, коллекциями, меню и списками покупок ограничены владельцем на backend.

Проверки: TypeScript, ESLint и реальная регистрация/вход через Keycloak прошли.

## 4. Рецепты, публикация и коллекция

Проверки: TypeScript и профильный ESLint прошли.

## 5. Недельные меню и снимки

- Реализованы несколько меню, семь дней, стандартные и пользовательские приёмы пищи.
- Поддержаны несколько рецептов, порции, дополнительные продукты, удаление и очистка приёма пищи или дня.
- Снимок рецепта создаётся backend при добавлении и содержит данные для отображения и покупок.
- Обычное редактирование меню не перезаписывает снимок, поэтому удаление, изменение или снятие оригинала с публикации не повреждает меню.

Проверки: TypeScript, ESLint и E2E-сценарий меню прошли.

## 6. Список покупок

- Общие ингредиенты объединяются только по `commonIngredientId` и единице; кастомные ингредиенты и дополнительные продукты не объединяются.
- Реализованы ручное добавление, изменение, удаление, отметка покупки и явное сохранение.
- Повторный расчёт заменяет список и запрашивает подтверждение только при наличии ручных изменений.

## Дополнение от 2026-08-04

- Форма рецепта поддерживает как URL изображения, так и загрузку JPG, PNG, WebP или GIF; загруженные файлы отдаются через frontend proxy `/uploads` и отображаются в карточках с резервным изображением при ошибке загрузки.
- Создана и применена миграция `docs/migrations/2026-08-04-menu-descriptions.sql`, добавляющая описание недельного меню. Комментарии дней хранятся в существующем JSONB-документе `days`.
- Новые меню создаются с пустыми днями. Приёмы пищи добавляются внутри дня из четырёх вариантов, блюда добавляются внутри приёма пищи с базовым числом порций и неизменяемым снимком рецепта.
- Добавлено модальное окно снимка рецепта с ингредиентами, пересчитанными на выбранное число порций; описание меню показывается до дней, комментарий дня после блюд.
- Дни выстроены в одну колонку, приёмы пищи внутри дня используют адаптивную горизонтальную сетку. Исправлены сжатие текста, container queries и перекрытие рабочей области фиксированным футером.
- Backend принимает только явно настроенные issuer Keycloak для `localhost` и `127.0.0.1`, продолжая проверять подпись JWT, realm и client id.
- E2E дополнены проверками загрузки изображения, URL изображения, описания, комментария, создания приёма пищи, базовых и изменённых порций, модального снимка и отсутствия горизонтального переполнения на 1280 и 390 пикселях.

Проверки этапа: Docker Compose пересобран, миграция применена, TypeScript, ESLint, production build, 6 unit-тестов и 2 Playwright-сценария прошли. У Webpack остаются только три предупреждения о размере production bundle.
